# Contributing to Android CLI
Thank you for your interest in Android CLI!
At this time, we are not accepting external pull requests or code contributions to this repository.
## Feedback and Bug Reports
If you encounter a bug or have feedback about Android CLI, please see the [official Android CLI documentation](https://developer.android.com/tools/agents/android-cli) for support and issue reporting channels.
## Community Guidelines
This project follows [Google's Open Source Community Guidelines](https://opensource.google/conduct/).
